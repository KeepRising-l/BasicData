# 学习进度追踪器

## 目的
跨会话记住用户的编程学习进度。项目 = **数据结构 + 设计模式**两条主线。

## 两条学习主线
1. **数据结构（重点）**：数组 → 链表 → 队列 → 栈 → 哈希表 → BST → AVL → 红黑树 → 布隆过滤器
   - 用户重点章节：哈希表、平衡二叉树、数组、红黑树、布隆过滤器
2. **设计模式**：创建型 → 结构型 → 行为型

## 清单数据文件
- 学习计划与进度：`LEARNING_PLAN.md`（与 SKILL.md 同目录）
- 每次更新都写回该文件，保持最新

## 会话开始（自动加载）
1. 读取 `LEARNING_PLAN.md`
2. 向用户汇报：上次学到哪、每章状态、下一步建议

## 学习协作模式（完整循环）
1. 概念讲解（图解）
2. 我提供**带注释引导的骨架** → 用户亲手写关键实现
3. 用户写完贴回 → 我逐段加注释、讲评
4. 我提供**带详细注释的参考答案**对照
5. 记录笔记/易错点/练习/掌握程度到清单

## 会话推进时
更新 `LEARNING_PLAN.md`：
- 章节状态：未开始 / 学习中 / 已完成
- 每章笔记、易错点
- 练习记录（练习名、是否跑通）
- 掌握程度：理解 / 能默写 / 能讲解

## 代码书写规则
- **关键代码由用户亲手写**，我不代笔关键实现
- 我提供：带注释引导的骨架、逐段讲评、带注释的参考答案
- 答案在用户写完后才给出，用于对照
